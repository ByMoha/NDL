# Nusuk AI chat · code and proposed data

The rules, the status of each component and where each value comes from are in **DESIGN.md › M9C Nusuk AI chat**. This folder holds only the files M9C points to: `nk-chat.js`, `nk-chat.css`, `nk-chat.tokens.css`, `tokens.proposed.json`, `icons.proposed.json`, `manifest.proposed.json`, `cards/` and `migrations/` (the chat team's proposals). Every DL release rebuilds them from the chat gallery's registry and checks them; the gallery itself runs on the DL's `tokens.css` and bundle.
