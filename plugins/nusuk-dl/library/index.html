Nusuk Design Language · coded package

Release of 2026-11-17. DESIGN.md 3.6.0 Tokens 3.11. Figma is the source of truth; this package mirrors it for concepts, decks and code. Open any preview in a browser (it loads IBM Plex Sans Arabic from Google Fonts; everything else is in this folder). Start with DESIGN.md, then docs/13-change-log.md (every change, with what iOS and Android must do). The guide's download index (download-index.json) lists every file with its SHA-256.

Use in a page

Load tokens.css, components/bundle.css, React 18 (copies in vendor/) and components/bundle.js, then render NusukDL.Button, NusukDL.Toolbar… Set data-theme on <html> (gold-light, gold-dark, green-light, green-dark, lavender-light, lavender-dark) and dir="rtl" for Arabic. Types: components/index.d.ts. iOS and Android: native/.
