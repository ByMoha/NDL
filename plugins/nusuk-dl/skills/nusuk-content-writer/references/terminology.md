## مصطلحات محظورة

| محظور | السبب |
|-------|-------|
| الحاج / المعتمر في سياق "المستخدم" | يقلل من قيمة المقام |
| تصريح (كبديل ل "احجز") | لغة رسمية ثقيلة |
| لا تفوّت / آخر فرصة | استعجال وهمي |
| الأفضل على الإطلاق | مبالغة تسويقية |
| نفيدكم بأن / يُرجى التكرم | بيروقراطية جافة |
| تم / يتم / سيتم | لغة آلية، استخدم الفعل المباشر |

## الهاشتاقات المعتمدة

- **#تطبيق_واحد** — الهاشتاق الرئيسي للحملات
- استخدم الهاشتاق وفق لغة المحتوى (عربي / إنجليزي)
- لا هاشتاقات رائجة غير مرتبطة بنسك

---

## العبارات الإيمانية المعتمدة

تُستخدم في مواضعها الطبيعية بدون مبالغة أو وعظ مباشر:

| العبارة | السياق |
|---------|--------|
| تقبل الله طاعتكم | ختام ردود التعليقات والرسائل |
| يسّر الله لك | عند الإرشاد والمساعدة |
| نسأل الله أن... | الدعاء العام |
| بإذن الله | عند الوعد بشيء مستقبلي |
| جزاك الله خيراً | في سياقات الشكر |
| رحلة مباركة | تمنيات لضيف الرحمن |

## ملاحظات على الشعار والهوية البصرية

- استخدم دائماً **الشعار المعتمد الرسمي** — هناك نسخ غير رسمية متداولة

- يمكن مقارنة القيمة المضافة بشكل عام دون تسمية
