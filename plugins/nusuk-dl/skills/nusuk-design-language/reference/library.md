## How the libraries depend on each other

Most DL files use components from other DL files, so one publish can leave several files behind. The full map, with every file's uses and used-by lists, is `library-dependencies.json` (read 15 November 2026). Publish in this order and, after each publish, open every file that uses the library, accept the update, and publish it too if it now shows changes. Stop when every file shows **No updates available** and **No changes**.

1. ⚙️ Foundation, 🎨 Icons, 👩🏻‍💻 Avatar, 📻 Switches, 🎹 Tabs, 🍟 Chips
2. 🕹️ Buttons, ⚡️ Animation
3. ‼️ Status Handlers, ⌨️ Inputs, 🧭 Navigation, 🃏 Cards, 🛎️ Notifications, 🔌 Misc, 🎫 Widgets, ⭐️ Rating, ⬇️ Dropdown, ⬆️ Modals, 💬 Chat UI, 🗺️ Map, 🏖️ Travel, 🖼️ Visual Assets. These use each other, so go round them until nothing changes; it took four rounds on 15 November.
4. 💸 Payment, 🎥 Media, 🔦 Tracker, 🛍️ Market, 📅 Date & Time
5. Files that only consume: Templates & Patterns, 🕋 Hajj Theme, 📱 App Assets, Nusuk Companion. Accept their updates; they are not published as libraries.

Loops to expect: Foundation and Visual Assets / Animation (Foundation's documentation pages); Buttons and Animation (Loading Icon); Inputs and Navigation (File Uploader Sheet and Direction Sheet); Cards, Misc, Chat UI and Widgets.

## Which file for which job

- **Tokens, text styles, effects, motion:** ⚙️ Foundation. Every other file consumes it; never copy its variables into another file.
- **A screen for a journey:** Navigation (toolbar, tab bar, sheets) + Cards + Status Handlers, then the feature file (Travel, Payment, Media, Chat UI, Map).
- **Brand moments and decks:** Nusuk Brand, Nusuk Brand (slides), Visual Assets, Hajj Theme.
- **Live activities, Dynamic Island, widgets:** Notifications and Widgets; animations in Animation.
