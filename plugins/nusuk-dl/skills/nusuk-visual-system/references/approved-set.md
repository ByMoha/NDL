# Selected artwork library

The library contains 17 selected artworks. Preserve the bundled images without repainting, resampling or enhancement. Use each scene for its specific construction and focal hierarchy; use Makkah City for the shared painting language.

Strong connected blue pigment identifies the focal passage. Sparse warm planes reveal form. Supporting edges lose completeness into pale washes, while essential geometry stays sound. Minimality is not a fixed object count, focal size or whitespace ratio: the Kaaba may retain focal ornament, Arafat a small summit monument, and Tawaf a dense anonymous crowd.
