## Rules for agents

1. Use token names from `tokens.json`, never raw hex. Each colour token has six values: `gold-light`, `gold-dark`, `green-light`, `green-dark`, `lavender-light`, `lavender-dark` (three brand themes × light/dark).
2. Figma px = iOS pt = Android dp.
3. Arabic first, right-to-left. Use leading/trailing, never left/right. Mirror directional icons (arrows, chevrons). Keep numbers, times and Latin text left-to-right inside RTL lines.
4. Type is IBM Plex Sans Arabic, Light (300) and Regular (400) only, line height 1.28 × size. Support Dynamic Type (iOS) and font scale (Android) from these base sizes.
5. Corner radius "Full" means a capsule (`Capsule()` / `CircleShape` or `RoundedCornerShape(50)`).
6. Do not invent states or colours. If Figma has no value, it is listed under Known issues with the rule to follow.

Glass BG is the surface of every floating control: toolbar icon groups, search bar, glass tabs, date pill, and (as `Primary Action`) the Primary button fill.

| Variant | Shape | Layers (bottom → top) |
|---|---|---|
| Current=Off, Navigation=On, Dark=Off | Capsule | Glass Effect at **50%** |
| Current=On, Navigation=On, Dark=Off | Capsule | Active Fill (light) · Glass Effect at 100% |

### 3.2 Layers

| Layer | Fill | Effect |
|---|---|---|
| **Glass Effect (light)** | Vertical linear gradient, white (`surface-01-white`). Alpha 37% at the top edge, rising to 100% at 88% of the height, 100% to the bottom | Figma GLASS: frost 2, refraction 0.4, depth 50, dispersion 0.4, light 0.8 at 150° |
| **Glass Effect (dark)** | Vertical linear gradient, Ink #070808. Alpha 25% at the top, rising to 50% at 88% of the height | Same GLASS |
| **Default Fill (light)** | Elliptical radial gradient centred on the top edge (horizontal radius 113% of width, vertical radius 50% of height): white 0% at the centre → white 100% at the rim and beyond | — |
| **Default Fill (dark)** | Same ellipse: Ink 0% → Ink 30% | — |
| **Shadows** (dark only) | White at 1%, blend Luminosity | Drop shadow x 0, y 1, blur 2, spread 0, #1A1C1F 3% |
| **Active Fill (light)** | Inset 20% from the leading/trailing sides, 21% from the top, 27% from the bottom. Radial gradient white 0% → `surface-longing` (gold #F5B13D) 100% | Layer blur 74: a soft gold glow |
| **Active Fill (dark)** | Same inset. Linear gradient gold #F5B13D 100% → Ink 0% | Layer blur 10 |

Effect style `Glass/Full` (cards and sheets): drop shadow 0 1 2 −1 #1A1C1F 4%, inner shadow 0 5 10 #1A1C1F 2%, inner shadow 0 1 0 white 50%, GLASS frost 2 (depth 40, other values as above).

### 3.3 Native build

- **iOS 26 and later:** `glassEffect(_:in:)` with `.regular` and `Capsule()` (or `RoundedRectangle(cornerRadius: 18)` for Navigation=Off) is the platform equivalent of Figma's GLASS effect. Group neighbouring controls in a `GlassEffectContainer`. Draw Default Fill, Shadows and Active Fill as backgrounds/overlays clipped to the same shape.
- **iOS 18–25:** `.background(.ultraThinMaterial, in: Capsule())`, then the Glass Effect gradient from §3.2 as an overlay, then the other layers.
- **Android:** Compose has no backdrop blur of its own. Use the Haze library (`hazeSource` on the content behind, the blur effect on the control, blur ≈ 2 dp) and draw the §3.2 gradients on top. Haze blurs on Android 12+ and draws a translucent scrim on older versions. Its API changed in 2.0, so pin the version. Without Haze, draw the gradients over `surface-01-white` at 85%.
- Shadows: SwiftUI `.shadow(radius:)` takes about half the Figma blur and has no spread, so shrink the shadow shape by the spread. Compose 1.9 (BOM 2025.08.00) adds `Modifier.dropShadow()` and `Modifier.innerShadow()` with radius, spread and colour.
- `Primary Action` is a flat fill: no material, no blur.
