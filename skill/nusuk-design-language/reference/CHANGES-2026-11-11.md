## In code

Sizes are pt on iOS and dp on Android. Both files are generated from `tokens.json`: `native/NusukTokens.swift`, `native/NusukTokens.kt`.

| Token | Swift | Kotlin | Before | Now |
|---|---|---|---|---|
| `button-padding-lr` | `NusukButton.paddingLr` | `NusukButton.PaddingLr` | 32 | 28 |
| `button-padding-md` | `NusukButton.paddingMd` | `NusukButton.PaddingMd` | 30 | 22 |
| `button-padding-sm` | `NusukButton.paddingSm` | `NusukButton.PaddingSm` | 22 | 18 |
| `button-padding-xs` | `NusukButton.paddingXs` | `NusukButton.PaddingXs` | 16 | 14 |
| `button-padding-icon-lr` | `NusukButton.paddingIconLr` | `NusukButton.PaddingIconLr` | 26 | 24 |

| Icon | SwiftUI | Compose |
|---|---|---|
| No icon | `.padding(.horizontal, NusukButton.paddingMd)` | `PaddingValues(horizontal = NusukButton.PaddingMd)` |
| Leading | `.padding(.leading, NusukButton.paddingIconMd).padding(.trailing, NusukButton.paddingMd)` | `PaddingValues(start = NusukButton.PaddingIconMd, end = NusukButton.PaddingMd)` |
| Trailing | `.padding(.leading, NusukButton.paddingMd).padding(.trailing, NusukButton.paddingIconMd)` | `PaddingValues(start = NusukButton.PaddingMd, end = NusukButton.PaddingIconMd)` |
| Icon only, loading | `.padding(.horizontal, NusukButton.paddingIconMd)` | `PaddingValues(horizontal = NusukButton.PaddingIconMd)` |
| Ghost | no padding | `PaddingValues(0.dp)` |

Android: Material 3 `Button` keeps a minimum size of 58 × 40 dp. Build the Nusuk button on a `Surface` or a `Box` with `clickable` so XS (30 high, 42 wide when icon-only) keeps its size.
