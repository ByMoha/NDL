## Rules for agents

1. Use leading and trailing, never left and right.
2. Read every number from the tokens.
3. Do not build anything from 🛍️ Market as a shared component yet: it is documented, not coded (MK8).

## 1 · Button padding

| Button | Leading | Trailing |
|---|---|---|
| No icon | `button-padding-*` 32 / 30 / 22 / 16 | same |
| Icon at the leading edge | `button-padding-icon-*` 26 / 24 / 20 / 14 | `button-padding-*` |
| Icon at the trailing edge | `button-padding-*` | `button-padding-icon-*` |
| Icon only or loading | `button-padding-*` both sides | |
| Icon only or loading, destructive | `button-padding-icon-*` both sides | |
| Ghost | 0 | 0 |

Before today the icon-side value applied to destructive buttons only. Check: MD with a 5-character Arabic label and one icon is 165 wide in Figma.
